# ПРОТОТИП LAB

Полноценный адаптивный сайт студии дизайна и цифрового производства полного цикла.

## Посмотреть сайт

**Live:** https://yuriyprojections123.github.io/prototip-lab-site/

## Запуск на macOS

1. Скачайте репозиторий: `git clone https://github.com/Yuriyprojections123/prototip-lab-site.git`
2. Откройте папку проекта.
3. Дважды нажмите `run-prototip-lab.command`.

Если macOS не разрешает запуск, выполните один раз:

```bash
chmod +x run-prototip-lab.command
```

Остановить локальный сервер можно сочетанием `Control+C` в окне Terminal.

## Структура

- `index.html` — структура и контент сайта
- `styles.css` — адаптивный дизайн и анимации
- `script.js` — меню, FAQ, scroll-reveal и работа брифа
- `assets/` — hero-изображение и favicon
- `prototip_logo.png` — официальный логотип
- `prototip_site_render.png` — исходный визуальный референс

Сайт не требует сборщика или стороннего фреймворка и может размещаться на любом статическом хостинге.
