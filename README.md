# ПРОТОТИП LAB

Статический многостраничный сайт студии дизайна и производства. Дизайн собран из исходного макета без фреймворков и внешних JavaScript-зависимостей.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Структура

- `index.html` — главная
- `services.html`, страницы направлений — услуги
- `portfolio.html`, `case-*.html` — портфолио и кейсы
- `about.html`, `contact.html` — студия и контакты
- `assets/` — локальные изображения и favicon
- `styles.css`, `script.js` — адаптивность, навигация, hover-состояния и форма

Форма контактов создаёт заполненное письмо на `hello@prototip-lab.ru` и копирует бриф в буфер обмена, если браузер разрешает доступ.
